A Python program that writes the funniest single-line patch note for a bug in real life / human biology (105 characters) to `/output/entry.txt` — the entry for make.fun's "Real-Life Patch Notes: The Comedy Changelog" bounty.

## The entry

> v1.8.2: fixed a bug where an itch spawned mid-back, exactly one centimetre beyond the reach of both arms.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
